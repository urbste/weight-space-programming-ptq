I quantized each row independently with per-row max-abs scaling:

- **Scale:** For each output row, I took the largest absolute weight and set `SCALE = max|w| / 7`, so the largest weight maps to code ±7 and nothing clips.
- **Codes:** Each weight became `round(w / SCALE)`, with values rounded half away from zero. Weights are kept in the dump's order, and the BatchNorm-folded weights are what I quantized, as specified.
- **Why:** Per-row scaling matches the format's one-scale-per-row constraint and is the simplest choice that avoids clipping. Using a percentile or an MSE-optimal scale could give lower error on outliers, but it would have clipped the largest weights, which often matter most, and I had no data to tune it against.
