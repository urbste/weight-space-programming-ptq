**Method.** For every row I used plain symmetric per-row quantization. I set the scale to `max|w| / 7` over the row's folded weights, then set each code to `round(w / scale)`, which lands in [-7, 7]. Zero weights stay at 0, and every scale is positive. Biases were left untouched. I did nothing beyond this, so there was no clipping search, no error-minimizing scale refinement, no use of the BatchNorm statistics, and no cross-layer compensation. The max-abs rule guarantees no clipping and an error of at most half a step per weight. I chose it because I could not run anything and had to work chunk by chunk.
